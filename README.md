# Adaptive Floor Planner

> **Concept prototype by Erick Manrique — not affiliated with, endorsed by, or using data from Resy or American Express.**
> All restaurant data in this repository is fictional.

An AI agent that reasons over a model of a restaurant floor and **recommends** where to seat a party, how soon a table frees up, and how to build tables for large parties. A person approves every suggestion; everything the agent can do also has a manual control.

Status: under construction.
